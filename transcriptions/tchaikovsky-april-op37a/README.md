## 转写方法

- **人工逐小节目读**（2026-10-19）。
  - 辅助脚本只做三件事：把每页按系统和小节线切成单小节图，拟合谱线并标出音高辅助线，按音头位置估算和弦音数。
  - 所有音高、时值和记号都由人眼确认；密集和弦另做 2–3 倍放大逐个数音头。
- **重复段**：重复的小节（17–22、41–50、55–58、62–74 等）都在扫描图上逐个看过，确认与前文相同后才在数据里照抄，不是按曲式推定的。差异只在表情记号（见下方标注）和谱号上。
- **调号与临时记号**：调号 2 个降号。临时记号按实际音高编码；导出时由工具按调号和小节内状态决定是否画变音记号，所以原谱的**还原提示记号**（如第 14 小节的 D♮4、第 57、59、76、80 小节 G 前的还原号）不一定画出来。
- **编码约定**：
  - **声部**：上行谱表分 `rh`（旋律 / 主声部）与 `rh2`（内声部伴奏）；下行谱表分 `lh`（和弦）与 `lh2`（第二声部：低音线，或第 10、12、18、20、68、70 小节左手的中音区旋律，第 40 小节左手的旋律）。
  - **谱号**：原谱左手经常换高音谱号，右手偶尔换低音谱号，共 20 处，都照印编码（`tools/export.py` 的 `clef_changes`）。各系统开头沿用前一系统的谱号，没有另外的换号。
  - **断奏点**照印，包括连线下的断奏点（portato，原谱 B 段与尾声左手和弦大量使用），都记作 staccato；**重音**（>）照印，共 20 个。
  - **延长记号**：第 86 小节最后的和弦，两行谱表都有。
  - **文字标注**（MusicXML `words`，斜体）：速度词与表情词照印（dolce、poco cresc.、più、rit.、a tempo、con grazia、dim.、morendo si poco a poco 等），力度记号（p、mf、f、pp、ppp）也记作文字。**渐强 / 渐弱楔形**记作文字 "<" / ">"，放在楔形起点（`@拍位`）；楔形的长度没有编码。
  - 文字标注一律放在楔形或文字所指的小节上；印在两行谱表之间的标记，归到上行谱表（标在谱表上方）。第 53、55 小节左手旋律下方的楔形归到下行谱表。
  - **没有编码**：踏板（Ped. / *）、指法、连线 / 圆滑线 / 乐句线，以及第 82–86 小节 morendo 后面的延续虚线。
- **MIDI**：同一时刻、同一音高的两个声部（第 13、21、71 小节的 D♭4 和第 14、22、72 小节的 D4，旋律与持续低音同度）各自发声，某些播放器会把较短的那个音截断或合并。断奏音只奏一半时值，重音力度加大；文字标注不影响回放。
- **导出工具**：`tools/export.py` 为本曲加了一条配置，并新增可选的 part 级 `clef_changes=[(小节, 拍内位置, 谱表, 谱号), …]`，用来在小节中途或末尾换谱号。只有配置了这一项才会写出，其他曲目的 `.musicxml` / `.mid` 逐字节不变（导出前后比对了全部 16 个文件的 SHA-1）。

## 核实结果

转写写完后另做了一遍独立核实：

- **时值**：每小节每个声部的时值总和都等于小节长度（`tools/check.py` 与另写的脚本各查一遍，弱起 = 八分音符，其余 = 3 个四分音符）。
- **纵向和声**：87 个小节逐个八分音符位置列出两行谱表同时发声的全部音，逐个确认是和弦音、经过音、倚音或辅助音。结果都说得通，例如第 3 小节 B♮ 减七、第 5 小节 A7、第 13 小节 C♯ 减七、第 24 小节 F7♭9、第 77、81 小节德意志增六、第 85 小节 C 减七上的旋律装饰。
- **左右手对位**：伴奏和弦都落在八分音符位置上，左右手的同时起音与原谱一致。
- **重复段**：35 组应当相同的小节（如 9 / 17 / 67、25–32 / 41–48、53 / 55、57 / 58）在导出结果里逐个八分音符比对，音高完全相同。
- 初读后改正（写入 `source.txt` 前）：
  - **第 2 小节左手**初读为 A3 C4 E♭4 F4。放大看，C4 位置只有一条加线、没有音头，应为 **A3 E♭4 F4**，与第 60 小节相同。证据：[`b02_b60_lh_chord_no_c4.png`](evidence/b02_b60_lh_chord_no_c4.png)。
  - **第 24、74 小节右手下声部**初读为 A♭3。放大后是两个错开的音头（二度），降号在 G3 高度，应为 **G♭3 + A3**，与 C 上的减七和弦（F7♭9 省根音）相合。证据：[`b24_b74_c4_without_dot_gb3_a3.png`](evidence/b24_b74_c4_without_dot_gb3_a3.png)。
  - **第 76 小节左手第 2 组和弦**，按音头估算有 4 个音。3 倍放大只有 3 个音头：**G3 B♭3 E♭4**。第 80 小节同理，为 G4 B♭4 E♭5。证据：[`b76_b80_three_note_chords.png`](evidence/b76_b80_three_note_chords.png)。

## 已知问题

- **力度只是文字标注**；渐强 / 渐弱楔形记为 "<" / ">" 文字，没有长度信息。少数标注的拍位是按印刷位置估的（多数放在小节开头）。
- 踏板、指法、连线 / 圆滑线 / 乐句线**没有编码**。
- 还原提示记号是否画出由导出工具决定，可能与原谱不同（见「转写方法」）。
- 第 85 小节的 A4 写成二分音符，与原谱的附点四分音符 + 连音线八分音符记法不同，时值相同。
- MIDI 的速度是自定的；rubato、rit.、a tempo 都不影响回放。
- 本次没有与电子谱比对。
